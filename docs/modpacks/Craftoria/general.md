### Mob farms 
<small>
<li>Ars drygmy farm with containment jars - great passive farm can farm a lot of mobs at decent but slow pace - server friendly </li>
<li>Dreadful dirt or equivalent spawns enemy mobs that are able to spawn in that world location. Very powerful general mob farm, can be tick accelerated with red stone pulse</li>
<li>Apotheosis spawners - silk touch or cardboard box a spawner, add an egg to change the spawn(mob grinding utils or capturing enchant) Super powerful, very customizable, needs to spawn in real world</li>
<li>If spawners / MGU spawner - never used not as powerful as other options </li>
<li>HNN (hostile neural networks) or MI equivalent (Model synthesizer) - very powerful specific mob drops simulator, does not spawn in world - very server friendly </li>
<li>Animal Pens passive mobs- very useful very powerful, very diverse, great to get early mid or late game - very server friendly </li>
<li>Paradox machine JDT - late game jdt - can rewind time to re-farm ores or mobs in an area - needs extra setup and maintenance to keep running</li>
</small>

### Ore generation
<small>
<li>Paradox Machine - mentioned above</li>
<li>IF - laser drill - location dependent and random</li>
<li>Mekanism Digital Miner - farms blocks in 64 block radius - needs to move to keep farming, can get pretty early game</li>
<li>Rftools  - very similar to the digital miner</li>
<li>Occultism miner - never used before,  very powerful</li>
<li>MI drills - very powerful upgrades as you progress thru the mod</li>
<li>AA lens of the miner - turns stones into ores, not server friendly, needs large amounts of stone or netherrack to keep it running</li>
<li>Create - multiple options, factory flow or a tunnel bore</li>
</small>

### Strip enchants
#### SFM
Obsidian floor

Toss as many books on Obsidian as there are enchants on the item  
Place anvil 2 blocks above Obsidian  
(3 or more is vanilla height to destroy items, not sure if sfm changes or remove this interaction)  
You get 1 book for each enchant and the item back
